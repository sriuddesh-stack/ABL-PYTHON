# Submission Checklist

Use this checklist before submitting the assignment.

## Repository setup
- [ ] Replace the student-detail placeholders in `README.md`.
- [ ] Check that all 10 case-study folders are present.
- [ ] Read each folder's `README.md` before running its program.

## Run and test each project
For every case-study folder:
- [ ] Open a terminal in that folder.
- [ ] Run `python main.py` (or `python3 main.py`).
- [ ] Test normal input.
- [ ] Test at least one boundary or invalid input where applicable.
- [ ] Compare the result with the test cases documented in the folder's README.
- [ ] Capture a genuine screenshot of the program and its output.
- [ ] Save the screenshot in that folder using a clear name, for example `output-screenshot.png`.

## Final review
- [ ] Confirm the program runs without errors.
- [ ] Confirm the screenshot matches the actual run.
- [ ] Confirm the assumptions and sample values are acceptable to your faculty.
- [ ] Do not include personal passwords or other private information in screenshots.

Note: Screenshots should be captured from your own actual program runs. Do not label sample text in documentation as a screenshot.
