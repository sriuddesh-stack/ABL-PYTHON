# Algorithm — Weekly Electricity Consumption Matrix

1. Start the program.
2. Define the appliance names and the seven days of the week.
3. Create an empty two-dimensional list to store daily electricity usage.
4. For each appliance, create an empty row.
5. Read the electricity units used by that appliance on each day.
6. If any reading is negative, display an error and stop.
7. Add each valid reading to the row.
8. Add the completed row to the usage matrix.
9. For each appliance, calculate the sum of its seven daily readings.
10. For each day, add the readings of all appliances to calculate that day's total usage.
11. Display the weekly total for each appliance.
12. Display the total electricity usage for each day.
13. Stop.

**Output:** Appliance-wise weekly totals and day-wise electricity totals.
