## Re-run locally

Open a case folder in a terminal and run:

```bash
python main.py
```

Use the values in that folder's `TEST_CASES.md` to reproduce the sample results. If your instructor specifically requires screenshots captured from a live IDE/terminal window, take those directly after running each program; the current images are rendered output examples.
