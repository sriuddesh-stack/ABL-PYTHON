# Algorithm — Student Marks Matrix Analysis

1. Start the program.
2. Define the student names and subject names.
3. Create an empty two-dimensional list to store marks.
4. For each student, create an empty row.
5. Read that student's mark for every subject.
6. Validate each mark. If a mark is outside 0–100, display an error and stop.
7. Add each valid mark to the student's row.
8. Add the completed row to the marks matrix.
9. For each student, calculate the row total and average, then display them.
10. For each subject, add the marks in that subject's column and calculate the subject average.
11. Compare student totals to find the student with the highest total.
12. Display the subject averages and the top performer.
13. Stop.

**Output:** Student totals and averages, subject averages, and the top-performing student.
