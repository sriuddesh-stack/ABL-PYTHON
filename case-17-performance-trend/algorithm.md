# Algorithm — Student Performance Trend Analysis

1. Start the program.
2. Define the subject names and create empty lists for previous and current marks.
3. Read the previous examination marks for all subjects.
4. Read the current examination marks for all subjects.
5. Select the first subject.
6. Subtract the previous mark from the current mark.
7. If the difference is positive, classify the subject as Improved.
8. If the difference is negative, classify the subject as Declined.
9. If the difference is zero, classify the subject as No change.
10. Repeat steps 6–9 for every subject.
11. Check the current marks and identify subjects with marks below 40.
12. Display each subject's trend and the list of subjects needing attention.
13. Stop.

**Output:** Subject-wise performance trends and subjects whose current marks are below 40.
